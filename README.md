# Chris Bridges Portfolio

Recruiter-focused GitHub Pages portfolio.

## Deploy
Upload the contents of this folder to the repository used by GitHub Pages. Keep `CNAME` and `.nojekyll` in the repository root.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive styling and dark mode
- `script.js` — theme persistence and footer year
- `resume.pdf` — downloadable résumé/cover-letter PDF

## Easy edits
Contact/profile links and project descriptions are in `index.html`. Colors are CSS variables at the top of `styles.css`.
